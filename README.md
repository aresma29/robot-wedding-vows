# One-Line Robot Wedding Vows

One line of robot wedding vows: a promise to share a charging dock, software updates, and the very last 1% of battery — until the warranty do us part.

## How it works

`main.py` reads the vow from `entry.txt` (resolved relative to the script's own location, so it works from any working directory) and prints it to stdout.
